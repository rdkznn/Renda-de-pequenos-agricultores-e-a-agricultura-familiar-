# Renda-de-pequenos-agricultores-e-a-agricultura-familiar-
A agricultura familiar é o cultivo em pequenas propriedades geridas pela própria família. Ela é vital porque produz a maior parte dos alimentos do dia a dia dos brasileiros, como arroz, feijão e hortaliças. Esse modelo gera empregos no campo, movimenta a economia de pequenas cidades e prioriza técnicas de produção mais sustentáveis.
